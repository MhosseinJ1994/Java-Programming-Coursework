# Java Programming Coursework

A collection of Java applications built during my Computer Science studies, focusing on
object-oriented programming, data structures, testing and software design patterns.

Each project lives in its own folder with its own README, build setup and tests.

## Projects

| Project | Description | Topics |
|---|---|---|
| [Tic-Tac-Toe](TicTacToe/TicTacToe) | A clickable Tic-Tac-Toe game against a computer player, with 3-round matches and a saved leaderboard | Swing GUI, OOP, Strategy pattern, file I/O, JUnit testing |

*More projects will be added here.*

## Tools

- **Java 25**
- **Gradle** (each project includes the Gradle wrapper, so no separate install is needed)
- **JUnit 6** and **AssertJ** for testing
